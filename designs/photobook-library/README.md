# Photobook library page

An interactive web page for Eastman Lab's in-house collection of 242 photobooks. Visitors scroll a shelf of book spines, hover to preview a cover, open a book for its details, search by title, photographer or publisher, and browse the full catalogue.

## Notes

- **Self-contained:** a single HTML file (about 8.1 MB) with 237 cover images embedded as JPEG data URIs. It loads no external scripts, fonts or images, so it works offline and on any static host.
- **Colors:** this page uses its own warm bookshelf palette (black ground, bronze accent `#b88a5d`, Georgia serif titles) instead of the orange-and-black sign palette in `BRAND.md`. The owner reviewed an orange version and chose to keep this original.
- **Cover images** are publishers' artwork for books the lab owns. Each book's "View cover source" link points to where its cover came from.
- **Published** as a claude.ai Artifact: https://claude.ai/artifact/DAHhsZKxVpBzdHovvauJKa
